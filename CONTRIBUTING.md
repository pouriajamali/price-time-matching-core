# Contributing

Start with README demo, CONTRACT and the exact source tests. Keep changes small and include a falsifiable counterexample plus independent model agreement. Preserve one caller, integer units, FIFO, original identities, conservation, deterministic trades and rejection before effects. Do not add market/account adapters or private/vendor data.

Use the pinned SDK and locked packages; warnings/analyzers fail the build. Test on both target OSes and inspect actual archives/notices. Correctness adapter durations cannot support a speed headline. Do not upload private logs, credentials or unrelated assets. Original contributions use MIT; keep upstream notices and attribution.
